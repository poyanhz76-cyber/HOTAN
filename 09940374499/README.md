# HOOTAN CLUB

سامانه سفارش بوفه با ظاهر مشکی/سبز، صفحه مشتری، پنل مدیریت جداگانه و پرداخت حضوری.

## امکانات فعلی
- نمایش محصولات، جست‌وجو و دسته‌بندی
- سبد خرید و ثبت سفارش با نام، شماره تماس و توضیحات
- پرداخت حضوری در بوفه
- پنل مدیریت با ورود ایمیل/رمز عبور
- مشاهده سفارش‌ها و تغییر وضعیت آن‌ها
- افزودن محصول و فعال/غیرفعال کردن موجودی
- آمار اولیه فروش و تعداد سفارش‌ها
- طراحی واکنش‌گرا برای موبایل و کامپیوتر

## اجرای محلی
1. Node.js نسخه 20 یا جدیدتر نصب باشد.
2. در پوشه پروژه ترمینال باز کن و اجرا کن:
   ```bash
   npm install
   cp .env.example .env
   npm run dev
   ```
3. آدرس محلی که Vite نشان می‌دهد باز کن.

## اتصال دیتابیس برای سفارش واقعی از چند گوشی
1. یک پروژه در Supabase بساز.
2. از SQL Editor محتوای `supabase/schema.sql` را اجرا کن.
3. از Project Settings > API مقدار Project URL و anon/public key را بردار.
4. در فایل `.env` قرار بده:
   ```
   VITE_SUPABASE_URL=...
   VITE_SUPABASE_ANON_KEY=...
   ```
5. در Supabase Authentication، یک کاربر مدیر بساز.
6. نقش مدیر را فقط از سمت امن سرور/داشبورد با app_metadata تنظیم کن. هرگز Service Role Key را در کد مرورگر یا GitHub قرار نده. برای شروع، در Supabase SQL Editor اجرا کن:
   ```sql
   -- جایگزین کنید: ایمیل کاربر مدیر
   update auth.users
   set raw_app_meta_data = coalesce(raw_app_meta_data, '{}'::jsonb) || '{"role":"admin"}'::jsonb
   where email = 'YOUR_ADMIN_EMAIL';
   ```
   سپس مدیر یک‌بار خارج و دوباره وارد شود.
7. `.env` را commit نکنید. فقط `.env.example` را در GitHub نگه دارید.

## استقرار
برای انتشار، پروژه را به Vercel یا Netlify متصل کن، Build Command برابر `npm run build` و Output Directory برابر `dist` باشد. متغیرهای محیطی بالا را در تنظیمات سرویس میزبانی وارد کن. در تنظیمات SPA rewrite همه مسیرها به `/index.html` هدایت شوند.

## نکات مهم قبل از استفاده واقعی
این نسخه یک پایه قابل اجراست، اما پیش از استفاده عمومی باید اعتبارسنجی قیمت و محاسبه مبلغ سفارش در سمت سرور/تابع دیتابیس انجام شود؛ محدودیت ضداسپم و سیاست‌های حریم خصوصی/نگهداری شماره تماس نیز اضافه شود. سفارش‌ها در حالت پیش‌نمایش فقط روی همان مرورگر ذخیره می‌شوند و بین گوشی‌ها مشترک نیستند. برای حالت واقعی، Supabase باید تنظیم شود.
